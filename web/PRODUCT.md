# PinCapture

## Product Purpose
Chrome extension + web app that captures browser clicks as step-by-step process guides and exports them as Word, PDF, PPTX, PPSX, or PPS files. A modern alternative to ScribeHow, built for internal process documentation.

## Users
Process documenters, operations analysts, IT trainers, and team leads at mid-size companies who need to create internal documentation without manual screenshotting or video recording. Invite-only early access.

## Brand
Name: PinCapture by flowlog.dev
Tone: Precise, direct, tool-focused. Not playful, not enterprise-cold. Like a well-made utility that respects the user's time.
Anti-references: SaaS-cream gradient heroes, glassmorphism, ScribeHow's pastel UI, hero-metric dashboards, dark-mode-for-aesthetics.

## Key differentiators
- Automatic click capture with annotation support
- Exports to five formats: DOCX, PDF, PPTX, PPSX, PPS
- Invite-only model — signals quality, not open signup chaos
- Chrome extension only activates during explicit capture sessions
